# JARVIS для Windows 11 (C# / .NET 8 / WPF)

Готовый проект. **JARVIS.exe в этой среде собрать не удалось** (нет .NET SDK и доступа к NuGet) —
проект ни разу не компилировался, возможны мелкие ошибки компиляции. Как получить EXE без установки чего-либо на ПК:

## Получить JARVIS.exe (ничего не устанавливая)
1. Создайте бесплатный аккаунт на github.com → New repository (приватный подойдёт).
2. Загрузите в него **содержимое** этой папки (Add file → Upload files; папка `.github` обязательна).
3. Вкладка **Actions** → «Build JARVIS.exe» → Run workflow (запускается и сам при загрузке).
4. Через 2–4 минуты откройте завершённый запуск → внизу **Artifacts → JARVIS-exe** → скачайте zip → внутри `JARVIS.exe`.
   Если сборка красная — откройте лог, скопируйте ошибку и пришлите мне: поправлю.

Альтернатива: на ПК с .NET 8 SDK запустите `build.bat` → `Release\JARVIS.exe`.
Готовый EXE — один файл (~150 МБ), .NET и Python не нужны.

## Требования к Windows
- Windows 11 x64, микрофон.
- **Русское распознавание речи**: Параметры → Время и язык → Язык и регион → Русский → Параметры языка →
  установить «Распознавание речи» (и «Преобразование текста в речь» для русского голоса Ирина/Павел).
  Без этого JARVIS скажет, что не нашёл русский модуль распознавания.

## Микрофон
Параметры Windows → Конфиденциальность → Микрофон: разрешить доступ приложениям для ПК.
В JARVIS: ⚙ Настройки → Микрофон (по умолчанию — системный). Проверка: «Джарвис» → «Слушаю.»
Кнопка «Говорить» принимает одну команду без ключевого слова. Можно вводить команды текстом в поле над историей.

## API (LLM, необязательно)
⚙ Настройки → «Использовать LLM» → адрес (любой OpenAI-совместимый, по умолчанию https://api.openai.com/v1),
модель, ключ. Ключ шифруется Windows DPAPI (файл `%APPDATA%\JARVIS\llm.key`), в exe и логах его нет.
LLM вызывается только если правила не поняли фразу и возвращает лишь JSON-намерение; выполняет всё C#-код по белому списку.
Ошибки: «Соединение с интернетом отсутствует.» / «Не удалось подключиться к языковой модели.»

## Голосовые команды
Приложения: «открой хром / Google Chrome / браузер», «запусти Telegram / Discord / Steam», «закрой Chrome», «открой калькулятор / блокнот / проводник»
Сайты: «открой YouTube / Google / Discord / ChatGPT / GitHub / Яндекс / ВК»
Папки и файлы: «открой загрузки», «открой папку документы», «найди фотографию с названием отпуск», «открой последнюю загруженную картинку»
Система: «сделай громкость 50 процентов», «выключи звук», «включи звук», «сделай скриншот», «заблокируй компьютер», «открой настройки Bluetooth / звука / экрана / обновлений»
Информация: «который час», «какая сегодня дата», «какая загрузка процессора», «сколько оперативной памяти используется», «сколько свободного места на диске C», «информация о системе»
Время: «поставь таймер на 5 минут», «будильник на 7 30»
Опасные (нужно сказать «подтверждаю»/«да»): «выключи компьютер», «перезагрузи компьютер» (через 10 с; отмена: Win+R → `shutdown /a`)
С LLM: «мне скучно, открой музыку» и другие свободные формулировки.

## Приложения
Находятся автоматически из меню «Пуск» (+ встроенные: Блокнот, Калькулятор, Проводник, Paint, Диспетчер задач, Параметры).
Свои — `%APPDATA%\JARVIS\applications.json`:
```json
{ "obs": { "path": "C:\\Program Files\\obs-studio\\bin\\64bit\\obs64.exe", "aliases": ["обс"], "process": "obs64" } }
```
Сайты — `%APPDATA%\JARVIS\websites.json` (`"url"`, только http/https). Перезапустите JARVIS.

## Как добавить новую команду
1. `Actions/…`: метод, возвращающий `ActionResult`.
2. `Core/SecurityManager.cs`: добавить имя в `Allowed` (и в `Dangerous`, если нужно подтверждение) и проверку параметров в `Validate`.
3. `Core/CommandParser.cs`: правило в `Rules` → `new Intent("имя", new() {["параметр"]="значение"})`; для LLM добавить в `Prompt` в `AI/LlmClient.cs`.
4. `Core/AssistantEngine.cs`: строка в `Dispatch`.

## Ограничения (честно)
- Удаление файлов и массовые изменения **не реализованы** намеренно (в `Dangerous` зарезервированы).
- Найденные исполняемые/скриптовые файлы не запускаются, только показываются в Проводнике.
- Магазинные приложения без ярлыка в «Пуске» (часть Spotify и т.п.) добавляйте через applications.json.
- Таймеры и будильники живут, пока запущен JARVIS.
- Качество System.Speech (офлайн-диктовка) ниже облачного; для замены реализуйте новый распознаватель вместо `JarvisSpeechRecognizer`, а голос — `ITextToSpeech`.
- Данные: `%APPDATA%\JARVIS` (history.db, settings.json, jarvis.log).
